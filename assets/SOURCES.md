# Asset sources

The four `profile-*.svg` files are original vector mastheads authored for this profile. Their wshy lettering is outlined from Satoshi Bold, a Fontshare / Indian Type Foundry typeface already used by the author's wshy-labs portal. No font binary or font loader is shipped. Chinese lettering uses the viewer's CJK system fonts. The artwork contains no animation, scripts, or external SVG dependencies.

Project screenshots remain in their original public repositories and are embedded directly:

- tick-stock-panel: `screenshots/看板.png` on `shy3130/tick-stock-panel`, showing the historical product interface.
- Codex Token Monitor: `docs/screenshots/models-v1.6.1-light.png` and `models-v1.6.1-dark.png` on `shy3130/codex-token-monitor`, showing the actual interface with fictional demonstration data.
- dsh-quota: `docs/images/hero.png` on `shy3130/dsh-quota`, showing the public project screenshots and their historical values.
- Contribution animation: the existing `output` branch of this repository, maintained by the existing snake workflow.

The compact `sponsor.svg` and `sponsor-mobile.svg` banners reuse the existing RunningHub icon and wordmark paths from `runninghub-banner-v3.svg`. The layout is new; the existing brand marks and lime identity are preserved. The banner contains no price, discount, or model-count claims.

No generated or newly copied raster images are shipped by this redesign. Original sponsor and TSP SVG assets are preserved for reuse.
