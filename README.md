## 01 — 精选作品

### [tick-stock-panel](https://github.com/shy3130/tick-stock-panel)

自托管、零运维的 A 股量化工作台。策略编写与历史回放、全市场毫秒级扫描、实时盯盘、因子挖掘，以及 LLM 驱动的个股分析与复盘。核心能力全部开放为 Open API 与 MCP 工具。

`Python` `FastAPI` `React` `TypeScript` `Polars` `DuckDB`

65 个开放 API · 12 个 MCP 工具 · 2400+ 测试 · 单容器部署 · [官网 tsp.shy313.com](https://tsp.shy313.com)
